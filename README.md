# 🎤 NOIzedVoice YTKaraoke Remote

A seamless, multi-device YouTube karaoke queue and remote system designed for parties, drinking sessions, and family gatherings! No more standing up just to pick a song—let everyone control the queue right from their own phones.

---

## ✨ Features

- **📱 Guest Web Remote:** Guests don't need to install any app. They simply connect to a local webpage using their phone to search and queue songs!
- **📺 Direct YouTube Integration:** Search and queue YouTube karaoke tracks directly into the host system.
- **🔄 Real-time Queue Management:** Smooth playlist handling so the party never stops and nobody hogs the mic.
- **🚀 Lightweight & Free:** Built specifically for Android hosts.

## 🛠️ How It Works (For Hosts & Guests)

1. **Host:** Install the APK on your Android device (the host machine/tablet connected to your TV or sound system).
2. **Guests:** Connect to the same Wi-Fi network (or hotspot) as the host, open the provided local web URL on any mobile browser, and start requesting songs!
